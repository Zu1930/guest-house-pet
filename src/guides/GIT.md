Работа с Git

1. Создание ветки по названию задачи

Перед началом работы создаем новую ветку с осмысленным названием. Используем префиксы в зависимости от типа задачи:
• feat – для новой фичи (feature)
• fix – для исправления багов
• epic – если это большая задача, содержащая множество подзадач

```
git checkout -b <тип>/<название-ветки>
```

2. Информативные коммиты

Каждый коммит должен содержать четкое описание изменений. Формат:

```
git commit -m "<тип задачи>(<название задачи>): <краткое описание>"
```

3. Как правильно пушить ветки

1. Добавляем изменения и создаем коммит:

   ```
   git add .
   git commit -m "feat(<название задачи>): <описание изменений>"
   ```

1. Пушим новую ветку в удаленный репозиторий:
   ```
   git push
   ```
1. Выравниваем нашу рабочую ветку с dev перед созданием PR:
   ```
   git rebase dev
   ```
1. После успешного ребейза делаем форс-пуш:
   ```
   git push -f
   ```
